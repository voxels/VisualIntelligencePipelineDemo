Edge Computing

Distributed actor system for offloading Vision, LLM, and Commerce inference to nearby Macs with Neural Engine.

Architecture

iOS Device (Visual Intelligence Pipeline)
    ↓ Bonjour discovery (_visualintel._tcp)
BonjourDiscoveryService — NWBrowser, TXT record parsing
    ↓ EdgeNodeInfo (chip, TOPS, models)
PipelineEdgeRouter — TOPS threshold routing + local fallback
    ↓ TLS 1.3 (NWTransportLayer)
macOS Edge Daemon — MenuBarExtra app
    ↓ Distributed Actors
Inference · Nowcasting · Commerce · ESG · Financial

Core Components

Component File Description
VisualIntelligenceActorSystem Edge/VisualIntelligenceActorSystem.swift Custom DistributedActorSystem with EdgeActorID, invocation encoder/decoder, result handler, transport protocol
BonjourDiscoveryService Edge/BonjourDiscoveryService.swift NWBrowser actor scanning _visualintel._tcp. Parses TXT records for chip family, neural engine TOPS, available models
NWTransportLayer Edge/NWTransportLayer.swift TLS 1.3 via Network framework. OSAllocatedUnfairLock connection pool, length-prefixed framing, 50MB limit
EdgeNodeService Edge/EdgeNodeService.swift 5 distributed actors + PipelineEdgeRouter with TOPS-based routing and local fallback

NormalizedRect x, y, width, height in 0-1 normalized coordinates

ModelStatus Model identity, name, state (.available, .loading, .unavailable)
