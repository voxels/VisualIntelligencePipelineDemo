Architecture Overview

Three-layer Swift Package Manager architecture with clear dependency direction:

DiverShared (pure Swift, zero deps)
    ↑
DiverKit (services, models, view models, ML)
    ↑
VisualIntelligencePipeline (app, views, intents, widget, extension)

Data Flow

Capture → enrich → persist → display:

Camera / Import / ShareSheet
    ↓
VisualIntelligenceViewModel — sifting, detection, review
    ↓
LocalPipelineService — orchestration
    ↓ (parallel enrichment)
Location · Weather · Web · Music · Aesthetics · Documents
    ↓
IntelligenceProcessor — on-device LLM (summaries, concepts, tags)
    ↓
Commerce Enrichment — ESG, Government APIs, Pricing, Scoring, Affiliate
    ↓
SwiftData + CloudKit — ProcessedItem → DiverSession
